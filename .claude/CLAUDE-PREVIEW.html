Turw-docs 项目概览

基于 VitePress 的个人博客和文档站点 — 学习材料与技术文档

Vue 3 SCSS VitePress CodeMirror 6 Tailwind CSS v4

⌨ 开发命令
命令 说明
bun run dev 启动开发服务器
bun run docs:build 构建生产站点
bun run docs:preview 本地预览构建结果
bun run format Prettier 格式化
bun run check:cspell 拼写检查
bun run generate-manifest 生成 CodeViewer 文件清单
📂 项目结构
docs/
├── .vitepress/
│ ├── config.mts ← VitePress 配置 + 自定义 markdown 插件
│ ├── theme/ ← 自定义主题 & Vue 组件
│ │ ├── index.ts ← 组件注册入口
│ │ ├── components/ ← 8 个自定义组件
│ │ └── style.scss
│ └── css/ ← 容器样式 / 图标 / mixins / Tailwind
├── frontdesign/ ← 前端文档
├── nuxt/ ← Nuxt.js 文档
├── server/ ← 服务端文档
├── code-style/ ← 代码风格 & VSCode 配置
├── sql/ ← SQL 文档
├── wsl/ ← WSL 相关文档
└── index.md ← 首页
🧩 自定义 Vue 组件
FlexProperty
CSS flex 布局属性展示
GridProperty
CSS grid 布局属性展示

图片预览
NuxterrorHandling
Nuxt.js 错误处理展示

全局复制按钮

FoldCodeBlock
可折叠代码块 + 复制按钮
FoldCodeGroup

⚠ 重要说明
▸ 基础路径: 站点配置为 /Turw-docs/
▸ 代码图标: public/assets/code-icon/ 中的 SVG 动态导入
▸ 包管理器: 使用 Bun（已从 pnpm 迁移）
▸ PostCSS: 使用 @tailwindcss/postcss，无需额外 autoprefixer
